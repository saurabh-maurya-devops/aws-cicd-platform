# Automated AWS CI/CD Deployment Platform

## Project Overview
This project aims to automate the build, testing, and deployment of a Python Flask web application using AWS and DevOps tools.

## Technology Stack
- Git and GitHub
- Python Flask
- Docker
- GitHub Actions
- Terraform
- AWS EC2

## Planned Workflow
1. Push application code to GitHub.
2. Run automated checks using GitHub Actions.
3. Build a Docker image.
4. Provision AWS infrastructure using Terraform.
5. Deploy the application to AWS EC2.
6. Verify the deployed application.

## Project Status
In Progress

## Objective
To build a practical CI/CD deployment workflow and gain hands-on experience with cloud infrastructure and automation.
